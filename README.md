## Game Description
**Title:** RIFT-KEEP

**Perspective:** Top-down

**Art style:** Low poly

**Inspiration:** *Slay the Spire 2* (randomized cards)

**Core loop:**
1. Main menu: play, settings, character select
2. Start a run: the map and enemy path are procedurally generated
3. Place towers from a deck of tower cards
4. Survive waves; enemies scale in number and health
5. Repeat until the base reaches 0 health or the player clears wave 50
6. Summary screen: retry or return to menu

## Controls
| Input | Action |
|-------|--------|
| WASD | Move camera |
| Q / E | Rotate camera |
| Scroll | Zoom |
| 1 / 2 / 3 | Select a tower to place |
| Left-click | Place tower / select a placed tower |
| Esc | Settings / pause |
| K | *(testing only)* Deal 5 damage to all enemies |
